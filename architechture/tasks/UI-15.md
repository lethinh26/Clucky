## UI-15 — Quản lý tài khoản nhân sự, hỗ trợ tìm kiếm, tạo, khóa hoặc mở tài khoản và gán quán đúng quyền

**Phụ trách:** Trần Nguyễn Hữu Khánh · **Sprint:** 1 · **Ước lượng:** 3 SP
**Phụ thuộc:** —

### 1. User Story

- **Là Admin**, tôi muốn quản lý tài khoản nhân sự, hỗ trợ tìm kiếm, tạo, khóa hoặc mở tài khoản và gán quán đúng quyền để quản lý dữ liệu và thao tác nghiệp vụ đúng quyền.

### 2. Công việc

- Render filter/list và actions theo role
- Mở confirm với đúng user
- Giữ trạng thái pending/error và cập nhật fixture sau thành công

**Không bao gồm:** provision tài khoản thật; API integration ở INT-61.

### 3. Contract và đầu ra

| Thành phần | Chi tiết cần bàn giao |
| --- | --- |
| Đầu vào / nguồn tin cậy | User/role/store fixtures, filters và action permissions. |
| Đầu ra / contract | Users table, role badge, lock/unlock confirmation và assign-store form. |
| Điểm giao tiếp / deliverable đã cam kết | react/pages/Users |

### 4. Tiêu chí hoàn thành

- Users table, role badge, lock/unlock confirmation và assign-store form.
- Khóa nhầm user khi list đổi: Confirm vẫn gắn đúng đối tượng
- Request pending: Không bấm lặp
- Manager: Không hiện assign-store chỉ dành Admin
- Admin/Manager thực hiện create/lock hợp lệ trong scope rồi reload: User/state đúng server, actor/quán không lấy từ field giả trong body
- Manager gán store chỉ dành Admin: Backend chặn
- Lock request lỗi: UI không giữ trạng thái khóa giả
- Reload: User/state đúng DB
- Manager A gửi assign-store hoặc lock Staff B: Backend chặn, không đổi user/session ngoài quyền
- API lock/create lỗi hoặc duplicate email: UI giữ dữ liệu nhập an toàn, không badge khóa/row thành công giả
- Manager tạo Staff, xếp ca hợp lệ rồi xem report quán mình: User/ca/report đúng server và role, không dựa mock session
- Luồng quán mình: Staff/ca/report khớp DB và role
- Manager gọi assign-store Admin-only: Bị chặn, không coi đây là bước happy path
- Manager đọc report B: Không lộ số liệu
- Manager gọi assign-store hoặc xếp ca/quản lý Staff B: Bị chặn, không đổi dữ liệu ngoài quyền
- Manager export B/all hoặc save Staff lỗi: Không lộ report, UI không success giả; evidence gồm file/readback không chỉ status
- Bàn giao contract, mã lỗi và kết quả tự kiểm thử kèm commit, môi trường, bằng chứng; ghi rõ lỗi hoặc phần còn bị chặn.

### 5. Điểm cần chốt

- Chốt các action được BE-19 cho phép; backend vẫn phải kiểm tra quyền.
