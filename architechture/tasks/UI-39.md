## UI-39 — Viết Dockerfile cho Next.js và React để build image production và chạy độc lập với cấu hình môi trường phù hợp

**Phụ trách:** Mai Sơn Việt · **Sprint:** 1 · **Ước lượng:** 3 SP
**Phụ thuộc:** —

### 1. User Story

- **Là người phát triển**, tôi muốn sử dụng viết Dockerfile cho Next.js và React để build image production và chạy độc lập với cấu hình môi trường phù hợp.

### 2. Công việc

- Tách build/runtime stages phù hợp app
- Cấu hình static/Next runtime và assets
- Kiểm tra route/reload/image behavior trong container

**Không bao gồm:** VPS deploy/HTTPS hoặc backend Dockerfile.

### 3. Contract và đầu ra

| Thành phần | Chi tiết cần bàn giao |
| --- | --- |
| Đầu vào / nguồn tin cậy | Next.js/React source/lockfiles, Docker build context và public API URL placeholders. |
| Đầu ra / contract | Dockerfile cho Customer/Admin và hướng dẫn build/run/health cơ bản. |
| Điểm giao tiếp / deliverable đã cam kết | frontend/*/Dockerfile |

### 4. Tiêu chí hoàn thành

- Dockerfile cho Customer/Admin và hướng dẫn build/run/health cơ bản.
- Direct URL reload: App vẫn trả route đúng
- Logo/favicon: Có trong image cuối
- Build env: Không chứa backend secret trong bundle
- Bàn giao contract, mã lỗi và kết quả tự kiểm thử kèm commit, môi trường, bằng chứng; ghi rõ lỗi hoặc phần còn bị chặn.

### 5. Điểm cần chốt

- Chốt public env build-time vs runtime theo framework; không dùng dev server như image production.
