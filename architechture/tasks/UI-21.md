## UI-21 — Màn hồ sơ Customer, sổ địa chỉ và đổi mật khẩu với kiểm tra dữ liệu và phản hồi lỗi không làm mất form

**Phụ trách:** Trần Nguyễn Hữu Khánh · **Sprint:** 1 · **Ước lượng:** 3 SP
**Phụ thuộc:** —

### 1. User Story

- **Là người phát triển**, tôi muốn sử dụng màn hồ sơ Customer, sổ địa chỉ và đổi mật khẩu với kiểm tra dữ liệu và phản hồi lỗi không làm mất form để triển khai và tích hợp đúng dữ liệu, quyền và contract của hệ thống.

### 2. Công việc

- Render thông tin và mở form
- Validate trường/confirm password
- Xác nhận thao tác và giữ giá trị khi request lỗi

**Không bao gồm:** Avatar upload BE-77 backlog; không quản lý hồ sơ người khác.

### 3. Contract và đầu ra

| Thành phần | Chi tiết cần bàn giao |
| --- | --- |
| Đầu vào / nguồn tin cậy | Profile/address fixtures, default selection và password form values. |
| Đầu ra / contract | Profile/address CRUD UI và đổi mật khẩu với error/success states. |
| Điểm giao tiếp / deliverable đã cam kết | app/profile/* |

### 4. Tiêu chí hoàn thành

- Profile/address CRUD UI và đổi mật khẩu với error/success states.
- Confirm password sai: Không submit thành công
- Đổi locale lúc nhập: Không reset form
- Xóa default address: UI theo policy được backend chốt
- Bàn giao contract, mã lỗi và kết quả tự kiểm thử kèm commit, môi trường, bằng chứng; ghi rõ lỗi hoặc phần còn bị chặn.

### 5. Điểm cần chốt

- Endpoint đổi mật khẩu cần chốt nếu API docs chưa mô tả; không tự tạo đường API mới.
