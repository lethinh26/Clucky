## UI-40 — Kiểm tra Dockerfile và build image các module backend, xác nhận cách cấu hình và khởi chạy container độc lập

**Phụ trách:** Mai Sơn Việt · **Sprint:** 1 · **Ước lượng:** 3 SP
**Phụ thuộc:** —

### 1. User Story

- **Là người phát triển**, tôi muốn sử dụng kiểm tra Dockerfile và build image các module backend, xác nhận cách cấu hình và khởi chạy container độc lập để triển khai và tích hợp đúng dữ liệu, quyền và contract của hệ thống.

### 2. Công việc

- Đối chiếu module list và artifact path
- Build image/jar theo service
- Ghi lỗi build/startup thiếu config thay vì bỏ qua

**Không bao gồm:** chứng minh API nghiệp vụ đã triển khai từ build thành công.

### 3. Contract và đầu ra

| Thành phần | Chi tiết cần bàn giao |
| --- | --- |
| Đầu vào / nguồn tin cậy | Gradle multi-project, Java toolchain, Dockerfiles và config bootstrap. |
| Đầu ra / contract | Kết quả build/package 11 module và Dockerfile/env/runbook đã đối chiếu. |
| Điểm giao tiếp / deliverable đã cam kết | Build OK |

### 4. Tiêu chí hoàn thành

- Kết quả build/package 11 module và Dockerfile/env/runbook đã đối chiếu.
- Docker context đúng: Lấy đúng jar của service
- Thiếu runtime config: Báo rõ dependency, không nhầm compile pass là healthy
- Một module lỗi: Report chỉ rõ module, không tuyên bố toàn bộ pass
- Bàn giao contract, mã lỗi và kết quả tự kiểm thử kèm commit, môi trường, bằng chứng; ghi rõ lỗi hoặc phần còn bị chặn.

### 5. Điểm cần chốt

- Audit Service mới thuộc BE-43, chưa tính là đã nằm trong 11 module lịch sử; không tự tăng scope/nghiệm thu.
