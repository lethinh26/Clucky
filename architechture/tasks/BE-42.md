## BE-42 — Cung cấp dashboard và báo cáo doanh thu theo quyền, hỗ trợ lọc kỳ, cửa hàng và xuất Excel hoặc PDF khớp số liệu

**Phụ trách:** Mai Sơn Việt · **Sprint:** 3 · **Ước lượng:** 5 SP
**Phụ thuộc:** BE-08, BE-09, KAFKA-07

### 1. User Story

- **Là người phát triển**, tôi muốn cung cấp dashboard và báo cáo doanh thu theo quyền, hỗ trợ lọc kỳ, cửa hàng và xuất Excel hoặc PDF khớp số liệu để triển khai và tích hợp đúng dữ liệu, quyền và contract của hệ thống.

### 2. Công việc

- Dashboard/revenue/export XLSX/PDF và UI filter/chart/readback
- Role scopes, date defaults, empty data, file correctness/limits
- KAFKA-07 sở hữu projection; không query DB Order/Payment, không suy doanh thu ca từ daily stats
- Chốt source projection/formula/watermark với KAFKA-07
- Dùng chung normalized filters/scoped query cho dashboard/revenue/export
- Nối UI filter và xử lý STAFF limitation, font Việt/file formats
- Kiểm totals bằng fixture theo ngày/quán, file thực và lỗi export

### 3. Contract và đầu ra

- API reports theo spec: from/to ISO date inclusive; thiếu to dùng hôm nay, thiếu from dùng đầu tháng của to; from>to/storeId<=0 trả400
- MGR ép quán JWT, quán khác/không quán403; ADM chọn quán/toàn chuỗi
- STAFF chỉ todayOrderCount scope STORE_DAY hôm nay, money/period fields null; date khác/revenue/export403, Customer/Shipper deny
- Dashboard periodRevenue/orderCount khớp revenue/export; today fields độc lập kỳ; file name phản ánh filter thực

### 4. Tiêu chí hoàn thành

- Admin kỳ/quán và toàn chuỗi hợp lệ: Dashboard period, revenue và file khớp cùng filter
- Thiếu from/to, đầu/cuối tháng và biên ngày: Defaults/inclusive theo contract, response trả kỳ áp dụng
- from>to/storeId<=0/format invalid: 400/lỗi catalog, không file success giả
- Manager sửa store filter sang B hoặc không assigned store: 403, không lộ số liệu/count/file
- Staff dashboard hôm nay: Chỉ todayOrderCount, money/period null không phải 0
- Staff đổi ngày/gọi revenue/export; Customer/Shipper truy cập: 403, không có file hoặc dữ liệu ngoài quyền
- Đổi kỳ khi xem dashboard: period fields đổi theo kỳ, today fields vẫn hôm nay
- Ngày/quán rỗng: Empty/zero/null đúng contract, không số liệu demo
- Projection trễ/replay/refund: Totals theo policy/watermark, không tự tính từ join liên DB
- Export Unicode tiếng Việt, tên dài, tổng và file name: XLSX/PDF đọc được, cùng scope/filter/rows với API
- Quá range/size hoặc lỗi tạo file: Lỗi có kiểm soát, không gửi file hỏng như thành công
- UI đổi filter nhanh/network lỗi: Không chart/file của request cũ, loading/retry rõ
- Yêu cầu thống kê ca thật khi chỉ daily stats: Ghi giới hạn/blocker, không nhận STORE_DAY là nghiệm thu ca
- Bàn giao contract, mã lỗi và kết quả tự kiểm thử kèm commit, môi trường, bằng chứng; ghi rõ lỗi hoặc phần còn bị chặn.

### 5. Điểm cần chốt

- Owner Report chốt money include/exclude refund/failed/double event cùng KAFKA-07
- Chốt timezone, file columns/range/size limits và freshness; không tự thêm export-job platform
- FR-STF-02 báo cáo ca chưa có projection thật: ghi BLOCKED phần ca, STORE_DAY không thay ca
