## UI-46 — Sửa responsive và thao tác bàn phím trên giỏ hàng, checkout, lịch sử, chi tiết đơn và màn đơn hàng của nhân sự

**Phụ trách:** Trần Đức Anh · **Sprint:** 1 · **Ước lượng:** 3 SP
**Phụ thuộc:** —

### 1. User Story

- **Là nhân viên cửa hàng**, tôi muốn sửa responsive và thao tác bàn phím trên giỏ hàng, checkout, lịch sử, chi tiết đơn và màn đơn hàng của nhân sự để xử lý nghiệp vụ đúng cửa hàng được phân công.

### 2. Công việc

- Kiểm tra grid/summary/dialog tại viewport nhỏ
- Thao tác quantity/form/status bằng bàn phím
- Kiểm tra focus/error/disabled và long text

**Không bao gồm:** E2E backend Order hoặc sửa domain ngoài Order.

### 3. Contract và đầu ra

| Thành phần | Chi tiết cần bàn giao |
| --- | --- |
| Đầu vào / nguồn tin cậy | UI Order routes, role/locale fixtures và viewport theo checklist chung. |
| Đầu ra / contract | Bản sửa responsive/a11y riêng domain Order và evidence retest. |
| Điểm giao tiếp / deliverable đã cam kết | Domain UI checklist |

### 4. Tiêu chí hoàn thành

- Bản sửa responsive/a11y riêng domain Order và evidence retest.
- Modal mở trên mobile: Nút xác nhận/đóng truy cập được
- Validation error: Focus/label giúp tìm trường sai
- Đổi viewport: Không mất state hoặc tràn ngang
- Flow backend thật trên các viewport/browser đã chốt, cả hai app: Không mất nội dung/action, UI state và quyền đúng, evidence ghi viewport
- Long product/address: Không che action hoặc tràn ngang
- API error trên mobile: Vẫn có retry/validation đọc được
- Modal/drawer: Action/close keyboard truy cập được
- Tên/địa chỉ dài, vi/en và API error trên màn nhỏ: Không tràn che CTA, validation/retry đọc và dùng được
- Mở form modal/drawer bằng keyboard rồi đóng: Focus/control truy cập được, không kẹt nền hoặc mất nút save/close
- Bàn giao contract, mã lỗi và kết quả tự kiểm thử kèm commit, môi trường, bằng chứng; ghi rõ lỗi hoặc phần còn bị chặn.

### 5. Điểm cần chốt

- Dùng cùng chuẩn viewport UI-34; không chứng nhận screen-reader coverage chưa thực hiện.
