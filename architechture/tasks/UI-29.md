## UI-29 — Báo cáo, cho chọn kỳ, cửa hàng, xem biểu đồ và xuất Excel hoặc PDF đúng quyền

**Phụ trách:** Mai Sơn Việt · **Sprint:** 1 · **Ước lượng:** 3 SP
**Phụ thuộc:** —

### 1. User Story

- **Là người phát triển**, tôi muốn sử dụng báo cáo, cho chọn kỳ, cửa hàng, xem biểu đồ và xuất Excel hoặc PDF đúng quyền để triển khai và tích hợp đúng dữ liệu, quyền và contract của hệ thống.

### 2. Công việc

- Chọn filter theo role
- Render cards/chart/table cùng range
- Hiển thị pending/error khi yêu cầu export

**Không bao gồm:** tính doanh thu từ mock để nghiệm thu báo cáo thật.

### 3. Contract và đầu ra

| Thành phần | Chi tiết cần bàn giao |
| --- | --- |
| Đầu vào / nguồn tin cậy | Report/chart fixtures, from/to/store/format và locale. |
| Đầu ra / contract | Report UI date picker/store filter/chart/table/export controls. |
| Điểm giao tiếp / deliverable đã cam kết | react/pages/Reports |

### 4. Tiêu chí hoàn thành

- Report UI date picker/store filter/chart/table/export controls.
- Range không hợp lệ: Không gửi export
- Manager: Không chọn toàn chuỗi trái quyền
- Dữ liệu rỗng: Chart/table không tạo doanh thu giả
- Admin/Manager xem cùng kỳ đúng scope rồi export: API, chart/table và file cùng bộ lọc/tổng số theo contract, file mở được khi người dùng kiểm chứng
- Manager sửa store: Không thấy dữ liệu quán khác
- Projection chưa có dữ liệu: Empty rõ, không mock revenue
- File export: Tổng/nhãn/timezone khớp API
- Manager A sửa storeId=B hoặc all trong query/export: Server giới hạn/deny theo policy, không rò rỉ dữ liệu qua file
- Projection chưa có dữ liệu hoặc export trả JSON lỗi: Empty/error rõ, không mock revenue và không lưu file giả thành công
- Manager tạo Staff, xếp ca hợp lệ rồi xem report quán mình: User/ca/report đúng server và role, không dựa mock session
- Luồng quán mình: Staff/ca/report khớp DB và role
- Manager gọi assign-store Admin-only: Bị chặn, không coi đây là bước happy path
- Manager đọc report B: Không lộ số liệu
- Manager gọi assign-store hoặc xếp ca/quản lý Staff B: Bị chặn, không đổi dữ liệu ngoài quyền
- Manager export B/all hoặc save Staff lỗi: Không lộ report, UI không success giả; evidence gồm file/readback không chỉ status
- Bàn giao contract, mã lỗi và kết quả tự kiểm thử kèm commit, môi trường, bằng chứng; ghi rõ lỗi hoặc phần còn bị chặn.

### 5. Điểm cần chốt

- Chốt metric và timezone với BE-42; file export thật thuộc INT-13.
